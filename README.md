# 공차 × Voice Order

**공차(GONG cha)** 매장을 대상으로 한 음성 주문 **발표용 프로토타입**입니다.  
말로 원하는 음료를 말하면 AI(목업)가 공차 메뉴 중 비슷한 후보를 이미지·쉬운 설명으로 보여주고, 터치로 좁혀 주문을 완성합니다.

> v4 발표자료(아키텍처·QR·창직)와 연동된 **공차 브랜드 목업** 버전입니다.

## 실행 방법

```bash
npm install
npm run dev
```

Chrome에서 `http://localhost:5173` 접속 · 마이크 권한 허용.

## 공차 데모 시연 시나리오

| 프리셋 | 예상 후보 (1라운드) |
|--------|---------------------|
| **시원하고 단 밀크티** | 고봉밀크티, 흑당 밀크티, 타로 밀크티 |
| **타로 맛 음료** | 타로 밀크티 (ice/hot) |
| **따뜻한 밀크티** | 따뜻한 고봉·타로 밀크티 |
| **달달한 음료** | 고봉, 흑당, 딸기 스무디 |

1. **음성**: `🎙 말하고 주문하기` 버튼을 **누른 채** "시원하고 단 밀크티 주세요" 등 발화
2. **프리셋**: 음성 실패 시 위 버튼만으로 전체 흐름 완주
3. **단골 재주문**: 한 번 주문 후 `지난번 그 음료`
4. **직원 호출**: 모든 화면 우측 상단

## 목업 데이터

```
src/data/brand.ts   # 공차 브랜드·프리셋
src/data/menu.ts    # 공차 메뉴 10종 + matchMenu 규칙
```

메뉴: 고봉·흑당·타로·얼그레이·말차·패션후르츠·레몬홍차·딸기 스무디 등  
썸네일은 이모지(오프라인 데모용).

## 화면 흐름

`idle` → `listening` → `candidates` → `confirm` → `done` → `rating` → `idle`
